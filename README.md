# PlayTrack

A lightweight Windows application and game playtime tracker built with C++ and Raylib.

## Planned Features

- Track time spent in selected Windows applications and games.
- Automatically detect running processes.
- Store accumulated playtime locally.
- Display total playtime through a simple Raylib interface.

## Tech Stack

- C++
- Windows API
- Raylib
- CMake
- Ninja
- MSYS2 UCRT64

## Status

Early development. Features are being implemented incrementally.
